Import from CSV file

Download your Google Sheet as a CSV (File → Download → CSV) and upload it here. Required columns: FirstName, LastName, DOB (YYYY-MM-DD), AgeGroup, Position. Optional: Position2, PlayerEmail, ParentEmail. Players already in the system will be skipped.

Import from Google Sheets

Alternatively, connect directly to a Google Sheet using a Sheet ID and API key.

Term dates

Set the start and end dates for each term. These are used to group data in the IDP.

Half-term review windows

Define up to 6 half-term windows. Each becomes a selectable period in the Half-Term Review tab. Use 6-week blocks aligned to your season.

Send and print all IDPs

Select an age group and term to generate IDPs for all players in that group. You can then print all or send emails individually.

Data management

Find and delete incorrect entries. Deletions are permanent and cannot be undone.

Player PIN management

Each player needs their PIN to access the player portal alongside their date of birth. Use the buttons below to send welcome emails or print a PIN sheet for distribution at training.
